# Security Policy

This repository is a public demonstration surface using **synthetic sync, packet, and exception data only**.

## Scope

- No live tenant integrations, connector credentials, payload bodies, or production audit trails should be committed here.
- The repo demonstrates integration-governance and review-posture patterns, not a production integration control plane.
- Any future embedded or hosted tier must use least-privilege integrations, read-only evidence paths where possible, and signed handoff packets.

## Reporting

If you find a security issue in the code or docs, open a private report through GitHub security advisories or contact the maintainer directly.
